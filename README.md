# PerformX Custom Cursors

An ultra-lightweight, high-performance animated custom cursor utility plugin for WordPress websites. Formatted to replace generic browser pointers with a premium, smooth-trailing geometric user experience interface.

## Features
* Smooth mouse-tracking physics engine
* Interactive auto-expanding link hover states
* Zero bloat, keeping site metrics fast and completely clear of performance impacts
