# PerformX Custom Cursors

An ultra-lightweight, high-performance animated custom cursor plugin for WordPress websites. Designed to replace default browser cursors with a premium, smooth-trailing experience.

## Features
* Smooth mouse-tracking physics
* Auto-expanding link hover states
* Zero bloat, zero performance impact
